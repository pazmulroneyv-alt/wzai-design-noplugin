# 无限画布·无内置渠道版（wzai-design-noplugin）

玩赚 AI 设计工作台（无限画布·无内置渠道自由配置版）桌面客户端，当前正式最新版本 **v1.0.2（1.0.2）**。

- 安装包：见 [Releases](https://github.com/pazmulroneyv-alt/wzai-design-noplugin/releases)
- 设置页内置升级入口：独立检测本仓库 Release、下载、SHA-256 校验并拉起安装（与内置渠道版仓库完全隔离）
- 校验值：每个安装包附 `.sha256` 文件
- 局域网副本：
  - v1.0.2 目录：`\\192.168.88.8\wz\无限画布二开\wzai-design-v1.0.2-noplugin\`
  - v1.0.1 目录：`\\192.168.88.8\wz\无限画布二开\wzai-design-v1.0.1-noplugin\`
  - v1.0.0 目录：`\\192.168.88.8\wz\无限画布二开\wzai-design-v1.0-noplugin\`

## 支持的安装包 (v1.0.2)

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | `Wanzhuan-AI-Design-Setup-1.0.2-noplugin-x64.exe` |
| Linux x64 | `Wanzhuan-AI-Design-1.0.2-noplugin-linux-amd64.deb`、`…-noplugin-linux-x86_64.AppImage` |
| Linux arm64 | `Wanzhuan-AI-Design-1.0.2-noplugin-linux-arm64.deb`、`…-noplugin-linux-arm64.AppImage` |
| macOS Intel | `Wanzhuan-AI-Design-1.0.2-noplugin-macos-x64.dmg` |
| macOS Apple Silicon | `Wanzhuan-AI-Design-1.0.2-noplugin-macos-arm64.dmg` |

Linux 为用户级安装：deb 仅放置只读安装源，程序安装到 `~/.local/share/wanzhuan-ai-design-noplugin/app`，运行不需要 root。
